Button — режим Desktop / Mobile

Один и тот же класс .ds-btn, разметка не меняется. Размеры приходят из токенов, режим переключается атрибутом data-mode="mobile" (файл iiko-ds-mobile/modes.css). Мобильные значения — из Figma Button_mob: высота 44, паддинги 12/16, текст 16px/500.

Замеры отрендеренных кнопок (не из макета, а из браузера)

Высоты сверяются с Figma: M Desktop 36 · M Mobile 44 · S 28 · XS 24. Тач-зона на мобиле считается достаточной от 44px.
