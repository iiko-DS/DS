Step — 12 вариантов

Пометки для ревью: (а) 12 вариантов — два ряда: Background=On (подложка #FAFAFA r8) / Background=Off, состояния Default/Hover/Press/Selected/Error/Disable; Selected — фон #F5F9FF + рамка #448AFF (в ряду Off — залитый круг с номером, как в компоненте), Error — #FFF8F8 / #FF5252, Disable — #9E9E9E; состав [иконка/номер 24][текст 14/20]; (б) цвета Hover/Press/Error-фонов и цвет иконок состояний в css не заданы — заморожены классами стенда на токенах компонента (решить в ДС); (в) тексты «Step 1», иконка — info. Журнал №134, №159.

Stepper line — 4 варианта

Пометки для ревью: (а) 4 варианта: Step=On (стрелки keyboard_arrow_right 24) / Step=Off (разделитель 8×1 #616161) × Background=On (подложки #FAFAFA / #F5F9FF / #F0F5FF / #F5F9FF+рамка / #FFF8F8 / #FAFAFA-серый) / Off; (б) Hover/Press/Error-фоны в css не заданы — заморожены классами стенда на токенах компонента (решить в ДС); (в) стрелки — контейнер ds-icon-size--6x (24), цвет — токен иконки. Журнал №134, №159.
