Пометки для ревью: (а) у Input cell / Select cell / Chips input cell в css реализованы только Default (:hover — фон и рамка ячейки) и --disabled; состояния Focus / Focus+Placeholder / Focus+Value / Error / Error+Hover — есть в наборах (8/7/8 вариантов), в css не выгружены вовсе — на стенде не показываем (в ДС решить: классы состояний + токены у полей forms-* есть); (б) «Vocus+Value» — опечатка имени варианта в наборе Figma (сохранена в классе css); (в) Element cell — контейнер под вложенный компонент: в наборе 11 видов, из несамостоятельных: Icon group, Input number, Slide toggle, Cell Input — см. одноимённые компоненты; у Status подпись наследует цвет варианта (fixes п. 1); (г) у чипа в ячейке крестик — svg из Figma, кадр выправлен в fixes пп. 5–6 (журнал №51); (д) футер в css фиксированный 980×65 с тенью 01 dp (токен shadows-01-dp-sl); в контексте ширину задаёт таблица; содержимое слота в наборе пустое — «Итого» как пример.
