Пометки для ревью: (а) логика набора зафиксирована с канвы: Type=Filled — фон контейнера и сегментов белый, выбранный сегмент показан АКЦЕНТНЫМ КОНТЕНТОМ (надпись/иконка); Type=Outlined — контейнер с рамкой, выбранный сегмент с акцентной заливкой; в css у `.ds-button-toggle--filled` базовый цвет надписи уже акцентный — уточнить, это ли имелось в виду (решить в ДС); (б) сегменты — реальные Button/Button icon (ds-btn / ds-btn-icon), клик переключает выбор (одиночный); (в) размеры сегментов M 36 / S 28 / XS 24 (у XS иконка 16); (г) у Filled-набора сегменты белые без рамок — фон = контейнер; д) состояния сегментов (hover/press) живые из Button. UX-примеры «Button toggle (UX Examples)» — сценарии (тексты дословно из канвы)

Переключение режима отображения

Пользователь наводит курсор на нужный вариант, кликает — выбор переключается на новый режим. Предыдущий выбранный вариант деактивируется.

Выбор периода в аналитике

Кадры канвы: Default / Hover на «Неделя» / Нажатие на «Месяц» и выбор месяца. Hover-подсветка сегмента — #FAFAFA (из Button).

Фильтрация по статусу

Состояния канвы: «Все элементы» и «Один выбран». Фильтр переключает список.

Множественный выбор параметров

Два выбраны — кадр пуст Все выбраны — кадр пуст
Клик по выбранному варианту снимает выбор; можно отметить несколько. Кадры «Два выбраны» и «Все выбраны» на канве пока пусты (в работе).

Заблокированные опции (disable)

Один вариант заблокирован — кадр пуст Hover на заблокированном — кадр пуст
Кадры «Один вариант заблокирован» и «Hover на заблокированном» на канве пусты; «Полностью заблокирован» — все три сегмента выключены (#9E9E9E, второй ряд).

Цветовая семантика — Подтверждение действия

Не выбрано — кадр пуст Отрицательный ответ — кадр пуст
«Положительный ответ» — выбор «Да» (Positive, зелёный #14B456). Кадры «Не выбрано» и «Отрицательный ответ» на канве пусты.

Цветовая семантика — Уровень приоритета

Средний приоритет — кадр пуст Высокий приоритет — кадр пуст
«Низкий» — выбран с Positive-заливкой (по канве). Заметка канвы: «Цвет выбранной кнопки передаёт смысл: • Positive (зелёный)…» (текст заметки в кадре сокращён).

Пометки для ревью: (а) группы «Color version accent/positive», «negative/warning», «combination» в наборе примеров построены зеркалом single selection с цветными заливками по названию — состав сегментов этих кадров при рекогносцировке не раскрывался; (б) кейс «???» — кадр без названия (строка таблицы действий + тумблер + поле Input, поле — другого компонента); текст заголовка в замере обрезан; (в) пустые кадры — как на канве (в работе), отмечены пунктиром; (г) сценарии кликабельны (single/multi/disable по кадрам).
