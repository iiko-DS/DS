# Дизайн-система iiko — рабочая папка

Здесь лежит ДС iiko и инструменты, которыми собираются её страницы.

Важно: это **не один репозиторий**, а три, и они должны лежать рядом в одной папке — генератор страниц обращается к соседним папкам по относительным путям (`iiko-ds-web` и `iiko-ds-mobile`).

## Структура

```
DS/
├── iiko-ds-web/          публичный репозиторий: компоненты, токены, стили, спецификация
├── iiko-ds-prototypes/   приватный репозиторий: прототипы экранов (в том числе KDS)
├── iiko-ds-mobile/       мобильный слой ДС: компоненты + страницы «Рекомендации» (генерируются)
├── _audit/               генератор страниц и данные, из которых они собираются
│   ├── rec/build.py                  сборка страниц компонентов
│   ├── rec/mock.py                   мок-данные, которые страницы показывают в примерах
│   ├── rec/data/<slug>.json          данные страницы компонента (что видно на странице)
│   ├── rec/data-tech/<slug>.json     технические заметки: источники, платформа, замеры
│   ├── rec/icon-map.json, icons.py   иконки для страниц
│   ├── rec/apply-values.py           применение пачки правок к data/*.json
│   ├── rec/out/                      превью, дайджесты и SPEC-инструкции по сборке
│   ├── platform/<slug>.json          данные платформы для мобильного слоя
│   └── platform/_src/                скрипты, которыми собираются platform/*.json
└── serve.py              локальный сервер, чтобы смотреть страницы в браузере
```

## Как начать работу

1. Склонировать три репозитория **в одну папку** и сохранить имена папок как есть:

   ```
   git clone https://github.com/Anders7Rusk/iiko-ds-web.git
   git clone https://github.com/Anders7Rusk/iiko-ds-prototypes.git
   git clone <репозиторий этой папки> DS     # внутри уже есть iiko-ds-mobile и _audit
   ```

2. Из установок нужен только **Python 3** — генератор использует стандартную библиотеку, сторонних пакетов нет.

3. Собрать страницы компонентов:

   ```
   python _audit/rec/build.py
   ```

   Страницы перезаписываются в `iiko-ds-mobile/prototypes/recommendations/`: `index.html`, 40 страниц по компонентам, общие `rec.css` и `rec.js`.

4. Посмотреть локально:

   ```
   python serve.py
   ```

   Адрес и порт сервер печатает в консоли.

## Где что править

- **Значения компонента на странице** — `_audit/rec/data/<slug>.json`, затем `python _audit/rec/build.py`.
- **Технические заметки по компоненту** (источники, платформенная спецификация, замеры) — `_audit/rec/data-tech/<slug>.json`.
- **Мобильные значения** — `_audit/platform/<slug>.json`; пересобрать их из исходников можно скриптами в `_audit/platform/_src/`.
- **CSS компонентов** — в своих репозиториях: `iiko-ds-web/components/…`, `iiko-ds-mobile/components/…`.
- **Прототипы экранов** — в `iiko-ds-prototypes/`.

## Что не коммитим

- Секреты: `.env`, `.env.*`, `.vscode/mcp.json` (в нём токен Figma — для команды есть `.vscode/mcp.example.json`).
- Кэш Python: `__pycache__/`, `*.pyc`.
- Разовые проверочные материалы: снимки экрана, пробы, временные страницы замеров.
