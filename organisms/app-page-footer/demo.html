Кадр страницы (заглушка)

Это демо стенд подвала страницы: внизу кадра — сам блок (подвал с итогами и действиями), выше — заглушка контента. Страница подключает ДС и page-footer — тот же набор, что и страницы-прототипы.

  • пресеты сверху меняют ширину кадра — блок растягивается по ширине контейнера;
  • тумблеры повторяют части компонента (Контент — левая часть с итогами, Действия — правая с кнопками); дефолт — всё включено;
  • клики в организме не заданы: кнопки — действия страницы. js организма делает только две вещи: подставляет иконки и переключает части — PageFooter.set(блок, { content: false, actions: false }) или атрибуты data-pf-*="off" на корне;
  • ячейки итогов — разметка организма на токенах (готового класса для семейства Table / Type=Text sec/over в коде пока нет).
