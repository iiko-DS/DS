# Блок-схемы: перевод макетов iiko в планшет и мобилу

> Наглядные схемы процесса. Повторяется для каждого экрана, начиная с раздела «Склад».

---

## 1. Главная схема процесса

```mermaid
flowchart TD
  START([Экран-пилот]) --> P1["Создать планшетную версию · ширина 768"]
  P1 --> P2["Разобрать, что изменилось"]
  P2 --> P3["Перевести компоненты на -mob"]
  P3 --> P4["Довести планшетный экран"]
  P4 --> M1["Создать мобильную версию · ширина 375"]
  M1 --> M2["Разобрать и перевести мобилу"]
  M2 --> M3["Довести мобильный экран"]
  M3 --> LOG["Свести журнал и категории"]
  LOG --> Q{"Поведение устоялось?"}
  Q -- "нет" --> P2
  Q -- "да" --> FIX["Зафиксировать в переменных:<br/>режим Mobile"]
  FIX --> CHK["Проверить каскад"]
  CHK --> NEXT{"Есть ещё экраны?"}
  NEXT -- "да" --> START
  NEXT -- "нет" --> DONE([Готово])
```

---

## 2. Решение по каждому компоненту

```mermaid
flowchart TD
  A["Компонент ведёт себя иначе на мобиле"] --> B{"Что именно изменилось?"}
  B -- "только числа:<br/>высота, паддинги, шрифт" --> C["Категория 1 · Режим Mobile"]
  B -- "состав или порядок элементов" --> D["Категория 2 · отдельный -mob компонент"]
  B -- "скрыт или заменён другим" --> E["Категория 3 · правило лейаута"]
```

---

## 3. Две независимые оси

```mermaid
flowchart LR
  THEME["Тема · ось цвета<br/>Light / Dark"] --> CT["Цветовые токены"]
  MODE["Режим · ось размера<br/>Desktop / Mobile"] --> ST["Размерные токены"]
  CT --> COMP["Компонент"]
  ST --> COMP
  COMP --> OUT["Один компонент — разный вид"]
```

---

## 4. Фиксация в переменных

```mermaid
flowchart TD
  A["Коллекция Component"] --> B["Добавить режим Mobile"]
  B --> C["Открыть переменную"]
  C --> D{"Отличается от десктопа?"}
  D -- "да" --> E["Внести мобильное значение"]
  D -- "нет" --> F["Оставить как есть"]
  E --> G["Следующая переменная"]
  F --> G
  G --> H{"Есть ещё переменные?"}
  H -- "да" --> C
  H -- "нет" --> I([Режим Mobile готов])
```

## 5. Каскад вложенных компонентов

```mermaid
flowchart TD
  MODE["Один режим Mobile<br/>на коллекции Component"] --> C1["Button → 44px"]
  MODE --> C2["Banner → мобильные паддинги"]
  MODE --> C3["Button внутри Banner → 44px"]
```
